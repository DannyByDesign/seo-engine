# 06 Learn

Read the strategy, intervention histories and prior outcome decisions at every cycle. Review
due observations before starting another intervention. Export mature analytics and preserve
comparable windows, deployment boundaries, property, timezone and cohorts. Evaluate Google
organic and ChatGPT referrals separately. API visibility probes are secondary diagnostics;
citations are not visits. No analytics means unknown outcomes, not a fabricated success.

Use each channel's result: enough Google data can inform a Google decision while ChatGPT
remains inconclusive. Retain an explicit channel-specific caveat. Do not let one sparse channel
erase useful observations in another, and do not call an observed change causal lift. Note
seasonality, campaigns, other site changes, indexing delay and product/market changes.

Record retain/refine/revert/defer with evidence and known/unknown cost. Insufficient evidence
normally gets a new review date. Deliberately ending measurement for other business reasons
requires the explicit inconclusive-retention acknowledgement; it does not establish growth.
Refine/revert creates actual follow-up work with linked source changes, not just a decision label.

Feed learning into the next research/positioning choice: which audience, promise, format,
query or conversion path seems supported; what failed; what should be investigated next.
Revise upstream artifacts when justified and preserve their old versions. Avoid a recurring
loop that merely publishes another article because a date arrived. Continue useful independent
work while low-traffic experiments accumulate data, without duplicating their target URLs.

Configure recurrence using the host's scheduler and established authority. Inspect the first
real run and record scheduler identity/timezone/next run. Quiet unchanged cycles; surface a
verified shipment, material result, failed check or specific input needed. A work packet or
successful scheduler command is not evidence that a useful website change shipped.
