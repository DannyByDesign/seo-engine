# 01 Understand

Run `run_strategy.py --action inspect` from the target root, then inspect the relevant files
and live website. The inventory is bounded; `truncated` means search remaining directories
yourself. Read project instructions, current routes/templates, product/service data, pricing,
checkout/signup/contact flows, documentation, tests, build scripts and hosting configuration.
Exclude the engine, dependencies, generated output, test fixtures and historical proposals
from business facts. Prefer current executable product data over an old README; conflicting
facts become explicit unknowns until resolved. Never read or copy secret values into research.

Discover who the offering serves, their task, what it actually does, credible differentiators,
conversion goals, geography/language, existing acquisition surfaces and owner constraints.
Derive search seeds from customer problems and capabilities, not just the brand name. Preserve
source paths and short exact supporting quotations. Distinguish a current product fact from
your hypothesis about who will buy it. Do not claim benefits that the code or owner cannot support.

Reuse a configured production URL or prior user-provided domain. For a new installation,
corroborate a candidate against deployment configuration and live canonical/site identity.
Ask only when conflicting plausible domains remain; continue local work meanwhile. Retain
subdirectory prefixes and locale structure. An unrecognized framework is an investigation
task: trace a page from source to rendered output and discover its real test/build commands.

Record `understand` using the contract. The author may be the agent. Record actual argv,
source files, product facts, audiences, seed queries, conversion goal and unknowns. Existing
authorization belongs in the operating notes with its original user instruction; recording it
does not expand scope. Never infer paid spending or external messaging authority from keys.

Done means another session can explain the business and modify a real page using this record.
The owner should not need to write a marketing brief to finish onboarding.
